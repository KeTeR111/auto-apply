# hh.ru Авто-отклик

Автоматические отклики на вакансии hh.ru: поиск → оценка через AI → отклик с сопроводительным письмом → логирование.

Письмо собирается **в коде** из шаблона. AI подставляет только две переменные: `interest` (задача из вакансии) и `experience` (что кандидат делал похожего). Модель не пишет письмо целиком — это защита от галлюцинаций и канцелярита.

---

## Быстрый старт

```bash
cd ~/Desktop/автоотклик
chmod +x start.sh
./start.sh --visible
```

При первом запуске `start.sh` создаёт venv, ставит зависимости и скачивает Chromium. Дальше — вход в аккаунт (см. ниже) и скрипт начинает работу.


## Режимы запуска

| Команда | Что делает |
|---|---|
| `./start.sh` | headless — браузер не виден, работает фоном |
| `./start.sh --visible` | окно браузера видно, после завершения ждёт Enter |

Первый запуск делайте с `--visible`: нужно войти в аккаунт.

---

## Вход в аккаунт

Скрипт пытается залогиниться сам по данным из `.env`. Если hh.ru показал капчу или запросил SMS, в режиме `--visible` появится:

```
╔══════════════════════════════════════════════╗
║  Войдите вручную в открытом браузере,        ║
║  затем нажмите Enter здесь.                  ║
╚══════════════════════════════════════════════╝
```

Войдите руками в окне браузера и нажмите Enter в терминале. Сессия сохранится в `browser_session/` — дальше можно запускать headless, логин больше не потребуется.

Если сессия протухла, удалите папку `browser_session/` и войдите заново.

## Конфигурация (.env)

### Аккаунт
```ini
HH_EMAIL=your@email.com
HH_PASSWORD=your_password
```

### AI модель

Локальная Ollama (по умолчанию, бесплатно):
```ini
AI_BASE_URL=http://localhost:11434/v1
AI_MODEL=qwen2.5:14b
AI_API_KEY=ollama
```

Скрипт сам запустит `ollama serve`, если она не запущена.

Переключение на OpenRouter (платно, но умнее):
```ini
AI_BASE_URL=https://openrouter.ai/api/v1
AI_MODEL=anthropic/claude-sonnet-4-5
AI_API_KEY=sk-or-v1-...
```

### Поиск
```ini
SEARCH_QUERIES=Аналитик данных;Data Analyst;BI аналитик
AREA=1                    # 1=Москва, 2=СПб, 113=вся Россия
SALARY_FROM=              # пусто = без фильтра
EXPERIENCE_PASSES=noExperience;between1And3
```

Поиск идёт по **названию вакансии** (`search_field=name`), полным перебором: каждый запрос × каждый уровень опыта, с пагинацией.

### Фильтры и лимиты
```ini
COMPANY_EXCLUDE=сбер;sber   # компании через ;
DAILY_LIMIT=200             # максимум откликов за запуск
MIN_SCORE=0.65              # порог релевантности 0.0–1.0
```

## Как скрипт решает, откликаться ли

Проверки идут по порядку, каждая следующая дороже предыдущей — ранние отсекают мусор до вызова AI.

**1. Фильтр по компании.** Название содержит строку из `COMPANY_EXCLUDE` → `🚫 ФИЛЬТР`.

**2. Статус вакансии.** Открывается страница, ищутся маркеры: уже откликались, отказ работодателя, вакансия в архиве, есть приглашение, исчерпан лимит hh.ru → `⏭️ ПРОПУСК (статус)`. **Токены не тратятся.** Повторные отклики при этом в лог не пишутся — только считаются для сводки.

**3. Фильтр по опыту.** Regex ищет в описании «от 4 лет», «5+ лет» и подобное. Пропуск только если требуется **больше 3 лет** → `⏭️ ПРОПУСК (опыт)`.

**4. Оценка AI.** Модель возвращает JSON: `score`, `reason`, `interest`, `experience`. До 3 попыток, если `interest`/`experience` пустые.

Промт явно запрещает снижать оценку за отсутствие коммерческого опыта — кандидат выпускник, и штраф за «нет опыта в отрасли» делал бы поиск бессмысленным. Снижение допустимо только за отсутствующие технологии (Spark, Scala, 1С, SAP).

**5. Бонус банкам.** Компания похожа на банк → `+0.15` к score.

**6. Порог.** `score < MIN_SCORE` → `⏭️ ПРОПУСК (оценка)`.

## Сценарии отклика

После клика «Откликнуться» hh.ru ведёт себя по-разному. Скрипт определяет модальное окно (`[role="dialog"]`, `.bloko-modal` и т.д.) и **работает только внутри него** — иначе кликает по рекомендованным вакансиям на фоне.

**A. Анкета работодателя.** Определяется по тексту «ответить на несколько вопросов» или по числу полей внутри модалки. Заполняется, затем отправляется.

**B. Попап с сопроводительным.** Одна textarea → вставляется письмо → отправка.

**C. Мгновенный отклик.** Сразу «Резюме доставлено» → скрипт жмёт «Приложить сопроводительное письмо» и досылает письмо.

### Подтверждение отклика

Отклик засчитывается **только** после верификации: скрипт возвращается на страницу вакансии и проверяет, что кнопка «Откликнуться» исчезла или появился текст «Вы откликнулись». Клика по кнопке отправки недостаточно — hh.ru может молча отклонить форму.

## Ответы на вопросы работодателя

### Типовые ответы (без AI)

Подбираются по ключевым словам в тексте вопроса:

| Тема | Ответ |
|---|---|
| Зарплата | по score: 120–150 тыс. |
| Формат работы | готов к гибриду и офису |
| Готовность выйти | сразу |
| Город | Москва |
| Мессенджер | Telegram |
| Уровень SQL | 7 из 10, с перечислением конструкций |
| Почему ищу работу | закончил вуз, ищу позицию в аналитике |
| Опыт Python / ML | стек из резюме |
| Инструменты | SQL, Python, Tableau, Excel |

Зарплата по score: `≥0.85` → 150 000, `≥0.75` → 140 000, `≥0.65` → 130 000, иначе 120 000.

### Усиленный режим (score > 0.7)

Для релевантных вакансий включается более настойчивое заполнение:

- **До 3 проходов** по форме. После каждого проверяется, разблокировалась ли кнопка отправки.
- **AI изучает форму целиком** — получает весь текст модалки и пронумерованный список полей, возвращает JSON-массив ответов. Это спасает поля, текст вопроса к которым не удалось привязать через DOM.
- **Финальная попытка** — если после всех проходов кнопка всё ещё заблокирована, делается ещё один проход и повторный клик.

### Когда вакансия пропускается

Единственная причина — **тест с кнопками выбора**: `input[type="radio"]` или больше одного неслужебного чекбокса. Такие анкеты требуют осмысленного выбора вариантов, автозаполнение здесь навредит. Всё остальное заполняется.

## Сопроводительное письмо

Шаблон в `templates.txt`:

```
Здравствуйте! Меня заинтересовала позиция {title}, особенно {interest}. Это пересекается с моим опытом — {experience}. Буду рад обсудить подробности в личных сообщениях.
```

Правила сборки:
- `interest` обрезается до 100 символов, `experience` — до 200
- если любое из них пустое, отклик уходит **без письма**
- приветствие «Здравствуйте» гарантируется кодом

Чтобы изменить письмо — правьте `templates.txt`, скрипт трогать не нужно.

## Логи

### logs/YYYY-MM-DD.log

Запись на каждую вакансию:

```
═══════════════════
[21:54:44] ✅ ОТКЛИК
───────────────────
Вакансия: Стажер-аналитик данных
Компания: ПАО Банк ПСБ
ID: 136982249
URL: https://hh.ru/vacancy/136982249
Оценка: 1.0
Причина: совпадение SQL и Python [+0.15 банк] | Анкета: заполнено 3 полей
Interest: выполнение задач по профилю подразделения
Experience: автоматизация отчетности в Excel и SQL логирование
───────────────────
Сопровод: Здравствуйте! Меня заинтересовала позиция...
```

### Статусы

| Статус | Значение |
|---|---|
| `✅ ОТКЛИК` | отклик отправлен и подтверждён на странице |
| `⏭️ ПРОПУСК (статус)` | отказ / архив / приглашение / лимит hh.ru |
| `⏭️ ПРОПУСК (опыт)` | требуется опыт больше 3 лет |
| `⏭️ ПРОПУСК (оценка)` | score ниже порога |
| `🚫 ФИЛЬТР` | компания в списке исключений |
| `⚠️ НЕ ОТПРАВЛЕНО` | попытка отклика не удалась |
| `⚠️ ОШИБКА` | AI не ответил или страница не открылась |

**Повторные отклики в лог не записываются.** Если на вакансию уже откликались, она пропускается тихо — только строка в консоли. При перезапуске скрипта таких вакансий набирается много, и в файле от них был бы один шум. Их количество показывается в итоговой сводке:

```
════════════════════════════════════════
📊 Итого: 7 откликов за сессию
⏭️ Пропущено повторных (не в логе): 23
📁 Лог: logs/2026-09-23.log
════════════════════════════════════════
```

### Причины неудачи

Поле «Причина» у `⚠️ НЕ ОТПРАВЛЕНО` содержит конкретику, а не общую фразу:

- `Кнопка «Откликнуться» отсутствует на странице`
- `Кнопка «Откликнуться» заблокирована работодателем`
- `Анкета содержит тест с кнопками выбора (radio/checkbox)`
- `Анкета найдена, но не удалось заполнить ни одного поля`
- `Анкета заполнена (3 полей), но кнопка отправки осталась заблокированной`
- `Анкета отправлена (3 полей), но hh.ru не подтвердил отклик`
- `Попап открыт, но кнопка отправки заблокирована или не найдена`
- `Показано «Резюме доставлено», но отклик не подтвердился`
- `После клика не появилось ни анкеты, ни попапа, ни подтверждения`
- `Таймаут 30с при отклике (hh.ru не ответил)`

### logs/questions.txt

Все вопросы работодателей с ответами и пометкой источника (шаблон / AI / AI-форма). Полезно для доработки списка типовых ответов.

## Диагностика

**Не проходит логин.** Запустите `./start.sh --visible` и войдите руками. Если и это не помогает — удалите `browser_session/`.

**Все вакансии получают низкую оценку.** Модель слишком строгая. Варианты: снизить `MIN_SCORE`, перейти на модель помощнее через OpenRouter, или смягчить правила оценки в промте (функция `ai_evaluate`).

**Много `⚠️ НЕ ОТПРАВЛЕНО` с «кнопка заблокирована».** hh.ru не засчитывает программный ввод в каких-то полях. Посмотрите `logs/questions.txt` — возможно, вопрос не распознан и ушёл пустой ответ.

**Скрипт ничего не находит.** Проверьте `SEARCH_QUERIES` и `AREA`. Поиск идёт только по названию вакансии, слишком узкие запросы дадут пустую выдачу.

**Ollama не отвечает.** Проверьте `ollama list` — модель из `AI_MODEL` должна быть скачана (`ollama pull qwen2.5:14b`).
